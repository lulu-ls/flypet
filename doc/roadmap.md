# FlyPet 路线图

配合 `design.md`（核心架构）与 `gameplay.md`（玩法系统）。**一期一期交付，每期都有可独立验收的产出。**

## 当前进度

- [x] 可行性结论：Mac / Win 都能做
- [x] 选定 Tauri 2 + Rust 状态机 + 小窗跟随
- [x] **Spike 完成**：demo 已跑通「全局鼠标 → 状态机 → 窗口跟随 → 点击穿透」，CPU ~1%，一次编译通过

## 一期（P0）：活的虫子 —— 基础体验

> 产出：一只可分发的桌面飞虫。所有玩法依赖此地基。

- [x] Spike：透明小窗 + 全局鼠标 + 窗口跟随 + 点击穿透
- [ ] 状态机打磨：fidget 挪动、落地冷却、工作区精确 inset（精确读菜单栏/任务栏高度）
- [ ] 空闲降频与性能核对（目标：栖息时 CPU < 2%）
- [ ] 托盘：显示 / 暂停 / 换皮肤 / 退出
- [ ] 三套皮肤：矢量 SVG 起步（透明背景 + 振翅动画），正式版换 PNG/APNG
- [ ] 打包 macOS / Windows，核对体积（目标 5–12MB）

## 二期（P1）：互动闭环 —— 喂食 + 亲密度 + 说话

> 产出：能喂、有数值、会回应的电子宠物。三件事捆绑交付，缺一环体验不成立。

- [ ] 宠物档案 `data.json` 持久化（gameplay §2）
- [ ] 投喂：托盘入口 → 注册 `Seek/Eat` 行为 → 皮肤补 `eat` 帧（gameplay §3）
- [ ] 饱腹冷却（30min）防刷
- [ ] 亲密度：等级表 / 加分规则 / 3 天未启动衰减（gameplay §4）
- [ ] 气泡窗口（第二个透明置顶窗，gameplay §6.1）
- [ ] 台词引擎：事件触发 → 加权随机 → 冷却去重（gameplay §6.2–6.3）

## 三期（P2）：成长线 —— 进化

> 产出：长期养成的理由。二期数据积累到位后，进化实现成本最低、收益最大。

- [ ] 阶段皮肤组：卵 → 幼虫 → 成虫 → 华彩（gameplay §5.2）
- [ ] 进化条件：首次投喂破壳 / 亲密度门槛 / 存活天数（gameplay §5.1）
- [ ] 进化演出：白光脉冲 → 换肤 → 台词（gameplay §5.3）
- [ ] 台词池按阶段 / 亲密度解锁；随机闲聊（低频）
- [ ] 高亲密度特效（栖息星光）

## 四期（P2）：打磨 —— 深度交互与系统项

- [ ] 点中虫子：hit-test 命中时动态关闭穿透（抚摸 = 亲密度来源之一）
- [ ] 多屏落点（锁当前屏）
- [ ] 开机自启
- [ ] 设置面板：警戒半径、速度、皮肤管理
- [ ] 饱食度完整数值化（可选）

## 明确不做

- Electron
- 全屏透明 WebView
- 在前端算世界坐标
- 读取其他窗口内容做「停在某个 App 上」
- 联网 / 账号 / 云存档（档案只在本机）
